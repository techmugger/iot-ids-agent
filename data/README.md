# Dataset files (not included in this archive — too large for distribution)

Place these files here:

- `UNSW_NB15_training-set.csv`
- `UNSW_NB15_testing-set.csv`
  Source: https://research.unsw.edu.au/projects/unsw-nb15-dataset (or Kaggle mirrors)

- `KDDTrain+.txt`
- `KDDTest+.txt`
  Source: official NSL-KDD distribution (search "NSL-KDD dataset")

The trained model artifacts in ../models/ were already produced from these
exact files (175,341/82,332 UNSW-NB15 records, 125,973/22,544 NSL-KDD
records) — you only need to re-download the CSVs if you want to re-run the
notebook/training scripts yourself.
